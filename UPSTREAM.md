# Source provenance

Onda is derived from [Clash-Projects/LastWave-Native](https://github.com/Clash-Projects/LastWave-Native), commit `3156a434d7e798a02df7e5fd47ae13f10a9c983a` on `main`, imported 4 October 2026.

The active `app/`, `audio/`, and Gradle build originate from this source. Its GNU GPL version 3 license is preserved in `LICENSE`; all upstream copyright and third-party notices remain applicable. Onda is a modified derivative, not an official LastWave release. Distribution must include the required corresponding source and notices under the license.

Onda changes include independent install identity/branding, isolated update behavior, backup exclusions, and first-party social and recommendation work. Existing Phase 1 Onda implementation is preserved under `foundation/` and is not included in the active music app build.

The source import excludes upstream release workflows, generated logs, screenshots, scratch tooling, and the duplicate legacy `reference zip/extracted/LastWave` project. The complete untouched shallow clone remains in ignored `.tools/lastwave-reference/` for inspection. No upstream signing keys or external service credentials are imported.
